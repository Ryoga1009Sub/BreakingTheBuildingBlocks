# 積み木崩しゲーム（仮称）

積み木・ブロックで作られた建物に対して、ボールを飛ばして崩すゲーム

<img width=500 src="./images/ゲームイメージ.png"/>


## ゲーム概要
- スマホ縦画面
- 3Dステージ
- 積み木で作られた城・建造物
- プレイヤーが玉を飛ばす
- 積み木に当たると物理演算で崩れる
- カメラを360°回して好きな方向から狙える
- ステージごとに「○個以上壊す」などのクリア条件??
- 飛ばす弾の種類が変えられたり、人を飛ばせたり。
   - 人の姿勢とかが変えられると面白そう

## 開発環境
- ゲーム全般：`Unity`
- コーディング環境：`VSCode`
   - 拡張機能
      - `Unity`（必須）
      - `Unity Code Snippets`
      - `Unity Snippets`
   - 言語：`C#`

    
## 実装ルール
- 機能ごとにGitでブランチを作成して作業後、PRを作成してマージをしながら進める事
- PR作るまでもない内容であればmasterに直接コミットでも可
   - README、gitignore更新など

## 開発の進め方
- 実装したい機能・流れを記載したissueを作成する
   - **1事象/機能に対し1issueとする**
   - 基本的に1つのissueに複数の要望を書かない
- 必ずPRのマージでもって実装を進める


## issue / PR
- 記述言語は`Markdown`形式
